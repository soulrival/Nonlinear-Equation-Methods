# Numerical Methods for Nonlinear Equations

Консольное приложение на C++ для реализации и сравнительного анализа численных методов решения нелинейных уравнений.

Проект выполнен в рамках курсовой работы по дисциплине «Проектная и научно-исследовательская деятельность» (ВятГУ, 2024).

## О проекте

Цель проекта — изучить и сравнить численные методы решения нелинейных уравнений, оценить особенности их работы, скорость сходимости и вычислительную эффективность.

В программе реализованы четыре численных метода:

- **Метод половинного деления (бисекции)** — последовательное уменьшение интервала, содержащего корень уравнения.
- **Метод Ньютона — Рафсона** — итерационный метод, использующий производную функции.
- **Метод секущих** — метод приближённого нахождения корня без вычисления производной.
- **Метод простой итерации** — последовательное уточнение приближения с использованием итерационной функции.

## Реализованные функции

Для сравнения методов используются две нелинейные функции:

1. Алгебраическое уравнение:

   \[
   f_1(x) = x^2 - x - 2
   \]

2. Трансцендентное уравнение:

   \[
   f_2(x) = e^x - 3x^2
   \]

Для метода Ньютона — Рафсона в программе также определены производные функций. Для метода простой итерации используются соответствующие итерационные функции.

## Сравнение методов

Программа выполняет решение каждого уравнения всеми четырьмя методами и выводит результаты в консоль.

Для каждого метода фиксируются:

- Найденное приближённое значение корня.
- Количество выполненных итераций.
- Время выполнения (в микросекундах).

Используется заданная точность `1e-6`. Для итерационных методов Ньютона — Рафсона, секущих и простой итерации предусмотрено ограничение в 100 итераций.

## Запуск проекта

Для сборки проекта потребуется Microsoft Visual Studio с установленной поддержкой разработки классических приложений на C++.

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/soulrival/nonlinear-equation-methods.git
   ```

2. Откройте файл `course.sln` в Microsoft Visual Studio.

3. Выберите конфигурацию сборки `Debug` или `Release` и платформу `x64`.

4. Выполните сборку проекта (`Build Solution`).

5. Запустите приложение (`Start Without Debugging` или `Ctrl + F5`).

После запуска программа последовательно выполнит расчёты для обеих функций и выведет результаты каждого численного метода.

## Результат

Проект демонстрирует практическую реализацию четырёх численных методов решения нелинейных уравнений и позволяет сравнить их по количеству итераций и времени выполнения.

Работа помогает изучить особенности применения методов, условия их сходимости и зависимость эффективности от свойств функции и начального приближения.
